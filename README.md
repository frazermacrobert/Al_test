# EX Values — Slider Prototype

A tiny, no-dependency web app that gives you **three sliders** to assess how your values are showing up — from **Underplayed (-2)** to **Overplayed (+2)**, with **0 = Balanced**.

- Edit the **value names inline** (click and type).
- Move the sliders to set scores.
- Use **Copy JSON** or **Download JSON** to export the results.
- **Reset to 0** puts all sliders back to Balanced.

## How to use (GitHub Pages)
1. Create a new GitHub repo (public is easiest).
2. Upload these files.
3. In the repo settings, enable **GitHub Pages** (select the `main` branch, `/root`).
4. Wait a moment; your prototype will be live at the Pages URL.

No build steps. Just static files.
